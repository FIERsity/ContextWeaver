# Human review files

## Glossary

Edit `state/glossary.csv` with a CSV-aware tool. Important columns:

- `term`: exact source term.
- `preferred_translation`: approved default translation; leave empty while uncertain.
- `allowed_variants`: pipe-separated acceptable alternatives.
- `evidence_segment_ids`: pipe-separated source evidence.
- `status`: `proposed`, `approved`, or `rejected`.

Approve only after checking every evidence Segment. Keep contextual or disputed choices proposed and explain them in `note`.

## Entities

Edit one JSON object per line in `state/entities.jsonl`. Set `kind` to a useful stable category such as `person`, `place`, `organization`, or `work`. Preserve aliases, evidence IDs, confidence, and review status.

## Issues

`state/issues.jsonl` is regenerated by validation. Do not resolve a defect by deleting the issue alone; correct the translation, glossary, entity record, or importer and validate again. Put non-deterministic literary or referential questions in `notes/` until a dedicated issue command exists.
